## Found and fixed

- **The MCP SDK is optional in Hermes.** Without it the GitHub server never connects and Bookwyrm
  starts with no GitHub tools (it said so rather than guessing). README setup now has a
  `hermes -p bookwyrm mcp test github` step.
- **`Warning: Unknown toolsets: mcp-github`** at start-up is harmless: printed before the MCP
  server connects. Documented.
- **No Docker:** `install.sh --github-mcp-bin <path>` wires the release binary in and keeps it
  across re-runs.

## Not proven here

- **Multi-turn confirmation.** Both runs were one-shot; run 2 was told up front not to read the
  note back. The read-back step in `record-sme-statement` needs an interactive run.
- Small corrections, quarantine and inbox intake: no quarantined drafts or published concepts
  existed on `main` to exercise them.

## Wake word — "hey bookworm"

Hermes' default wake engine (openWakeWord) needs macOS 15+ on Apple Silicon and only knows
"hey hermes", so the profile uses sherpa, which listens for a typed phrase. Tested with the
same sherpa model (`kws-zipformer-gigaspeech-3.3M`), keyword tokenizing and sensitivity (0.6)
as Hermes, on Piper `en_US-lessac-medium` speech at three speeds:

| Keyword as configured | Spoken clips caught | False triggers (6 other sentences × 3) |
|---|---|---|
| `hey bookwyrm` | 0 / 12 | 0 / 18 |
| `hey bookworm` | 11 / 12 | 0 / 18 |

The phrase is spelled as it is said. Synthetic speech is not a real voice in a real room, so
the sensitivity may need tuning on the Mac. Piper voices download from Hugging Face on first
use; a network that blocks it will need the voice file placed by hand (`tts.piper.voice` takes
an absolute `.onnx` path).

## Token scope — proven on the Mac

The cloud test could not exercise the fine-grained token (its proxy substitutes credentials).
Checked on Dee's MacBook with the token from the Bookwyrm profile's `.env`, by a write probe
that cannot succeed (a branch from an all-zero commit id), so the status code shows only
whether the token may write:

| Repo | Result | Meaning |
|---|---|---|
| `dfirmin/bookwyrm` (outside scope) | 403 | token may not write |
| `dfirmin/archivist-knowledge-01` | 422 | token may write; rejected only for the fake commit |

A *read* is no test of scope for public repos: any token can read them (bookwyrm returned 200).
